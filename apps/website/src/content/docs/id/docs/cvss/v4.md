---

**CVSS v4.0** adalah standar saat ini yang diterbitkan oleh FIRST.Org. Versi ini menggantikan sakelar biner `Scope` dari v3.x dengan metrik dampak eksplisit untuk **Sistem Rentan** (`VC, VI, VA`) dan **Sistem Berikutnya** (`SC, SI, SA`), memisahkan kondisi prasyarat ke **Attack Requirements (`AT`)**, menyempurnakan **User Interaction (`UI`)** menjadi tiga tingkat, dan memperkenalkan metrik **Supplemental** bersama nomenklatur skor resmi (`CVSS-B`, `CVSS-BT`, `CVSS-BE`, `CVSS-BTE`).

Buka [Kalkulator CVSS v4.0](https://cvss.my.id/calculator/v4.0).

## Nomenklatur Resmi

CVSS v4.0 mewajibkan penunjukan kelompok metrik mana yang berkontribusi pada skor numerik:

- **`CVSS-B`**: Metrik Base saja.
- **`CVSS-BT`**: Metrik Base + Threat.
- **`CVSS-BE`**: Metrik Base + Environmental.
- **`CVSS-BTE`**: Metrik Base + Threat + Environmental.

**Metrik Supplemental (`S, AU, R, V, RE, U`) tidak pernah mengubah skor numerik atau label nomenklatur.** Metrik tersebut dicatat dalam vector string kanonis untuk memberikan konteks terstruktur bagi tim respons insiden.

## Metrik Base (11 Wajib)

Kesebelas metrik Base harus ditentukan sebelum vector CVSS v4.0 dinyatakan valid.

### Metrik Exploitability

| Metrik | Kode | Nilai | Deskripsi |
| --- | --- | --- | --- |
| **Attack Vector** | `AV` | `N` (Network), `A` (Adjacent), `L` (Local), `P` (Physical) | Konteks yang memungkinkan eksploitasi kerentanan. |
| **Attack Complexity** | `AC` | `L` (Low), `H` (High) | Upaya yang diperlukan penyerang untuk menghindari atau melewati teknologi pertahanan atau peningkatan keamanan. |
| **Attack Requirements** | `AT` | `N` (None), `P` (Present) | Kondisi atau variabel penyebaran dan eksekusi pada sistem rentan yang memungkinkan serangan. |
| **Privileges Required** | `PR` | `N` (None), `L` (Low), `H` (High) | Tingkat hak istimewa yang harus dimiliki penyerang sebelum berhasil mengeksploitasi kerentanan. |
| **User Interaction** | `UI` | `N` (None), `P` (Passive), `A` (Active) | Apakah eksploitasi memerlukan partisipasi pengguna manusia selain penyerang. |

### Metrik Dampak pada Sistem Rentan

| Metrik | Kode | Nilai |
| --- | --- | --- |
| **Vulnerable System Confidentiality** | `VC` | `H` (High), `L` (Low), `N` (None) |
| **Vulnerable System Integrity** | `VI` | `H` (High), `L` (Low), `N` (None) |
| **Vulnerable System Availability** | `VA` | `H` (High), `L` (Low), `N` (None) |

### Metrik Dampak pada Sistem Berikutnya

| Metrik | Kode | Nilai |
| --- | --- | --- |
| **Subsequent System Confidentiality** | `SC` | `H` (High), `L` (Low), `N` (None) |
| **Subsequent System Integrity** | `SI` | `H` (High), `L` (Low), `N` (None) |
| **Subsequent System Availability** | `SA` | `H` (High), `L` (Low), `N` (None) |

## Metrik Threat (1 Opsional)

| Metrik | Kode | Nilai | Default (`X`) |
| --- | --- | --- | --- |
| **Exploit Maturity** | `E` | `X` (Not Defined), `A` (Attacked), `P` (Proof-of-Concept), `U` (Unreported) | Saat `E:X` dipilih atau dihilangkan, kalkulator mengasumsikan `A` (Attacked) sebagai nilai bawaan untuk kasus terburuk. |

## Metrik Environmental (14 Opsional)

- **Security Requirements (`CR, IR, AR`)**: `X` (Not Defined, diperlakukan sebagai `H`), `H` (High), `M` (Medium), `L` (Low).
- **Modified Base Metrics**: `MAV, MAC, MAT, MPR, MUI, MVC, MVI, MVA, MSC, MSI, MSA`.
- **Nilai Safety Impact pada Sistem Berikutnya**: `MSI` (Modified Subsequent System Integrity) dan `MSA` (Modified Subsequent System Availability) menyertakan opsi tambahan **`S` (Safety)** di atas `H` ketika eksploitasi dapat membahayakan keselamatan fisik manusia.

## Metrik Supplemental (6 Opsional)

Metrik Supplemental sepenuhnya bersifat informasional dan **tidak pernah mengubah skor numerik CVSS v4.0**:

- **Safety (`S`)**: `X` (Not Defined), `N` (Negligible), `P` (Present)
- **Automatable (`AU`)**: `X` (Not Defined), `N` (No), `Y` (Yes)
- **Recovery (`R`)**: `X` (Not Defined), `A` (Automatic), `U` (User), `I` (Irrecoverable)
- **Value Density (`V`)**: `X` (Not Defined), `D` (Diffuse), `C` (Concentrated)
- **Vulnerability Response Effort (`RE`)**: `X` (Not Defined), `L` (Low), `M` (Medium), `H` (High)
- **Provider Urgency (`U`)**: `X` (Not Defined), `Clear`, `Green`, `Amber`, `Red`

## Cara Kerja Penilaian MacroVector CVSS v4.0

Berbeda dari rumus aljabar v3.x, CVSS v4.0 memetakan metrik efektif (di mana metrik Environmental yang dimodifikasi menggantikan metrik Base bila ditentukan) ke **MacroVector** 6 digit (`eq1` sampai `eq6`):

1. **`eq1`** (0-2): Prasyarat exploitability (`AV, PR, UI`).
2. **`eq2`** (0-1): Kompleksitas dan persyaratan (`AC, AT`).
3. **`eq3`** (0-2): Dampak pada sistem rentan (`VC, VI, VA`).
4. **`eq4`** (0-2): Dampak pada sistem berikutnya (`SC, SI, SA`, termasuk `MSI:S` dan `MSA:S`).
5. **`eq5`** (0-2): Threat Exploit Maturity (`E`: `A=0`, `P=1`, `U=2`).
6. **`eq6`** (0-1): Gabungan Dampak pada Sistem Rentan dan Security Requirements (`VC/VI/VA` dengan `CR/IR/AR`).

Jika keenam metrik dampak efektif (`VC, VI, VA, SC, SI, SA`) bernilai `N`, skornya adalah `0.0 (None)`. Jika tidak, mesin akan mencari skor dasar MacroVector aktif dalam tabel pencarian resmi FIRST berisi 270 entri, menghitung jarak tingkat keparahan dari vector dengan tingkat keparahan tertinggi dalam MacroVector yang sama, lalu melakukan interpolasi terhadap MacroVector berikutnya yang lebih rendah di seluruh `eq1..eq6`, dengan pembulatan ke satu tempat desimal.
