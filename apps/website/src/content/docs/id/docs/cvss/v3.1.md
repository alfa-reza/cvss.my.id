**CVSS v3.1** (diterbitkan Juni 2019) memperjelas panduan dari v3.0, menyempurnakan rumus **Environmental `ModifiedImpact`** untuk Scope Changed (`MS:C`), dan mendefinisikan fungsi **`Roundup`** yang aman untuk floating-point secara tepat di Lampiran A (`roundup(x) = ceil(round_to_nearest_int(x * 100000) / 10000) / 10`).

Buka [Kalkulator CVSS v3.1](https://cvss.my.id/calculator/v3.1).

## Metrik Base (8 Wajib)

| Metrik | Kode | Nilai |
| --- | --- | --- |
| **Attack Vector** | `AV` | `N` (Network = `0.85`), `A` (Adjacent = `0.62`), `L` (Local = `0.55`), `P` (Physical = `0.20`) |
| **Attack Complexity** | `AC` | `L` (Low = `0.77`), `H` (High = `0.44`) |
| **Privileges Required** | `PR` | `N` (None = `0.85`), `L` (Low = `0.62` saat `S:U`, `0.68` saat `S:C`), `H` (High = `0.27` saat `S:U`, `0.50` saat `S:C`) |
| **User Interaction** | `UI` | `N` (None = `0.85`), `R` (Required = `0.62`) |
| **Scope** | `S` | `U` (Unchanged), `C` (Changed) |
| **Confidentiality** | `C` | `N` (None = `0.00`), `L` (Low = `0.22`), `H` (High = `0.56`) |
| **Integrity** | `I` | `N` (None = `0.00`), `L` (Low = `0.22`), `H` (High = `0.56`) |
| **Availability** | `A` | `N` (None = `0.00`), `L` (Low = `0.22`), `H` (High = `0.56`) |

## Metrik Temporal (3 Opsional)

Saat dihilangkan atau diatur ke `X` (`Not Defined`), setiap metrik Temporal menggunakan bobot bawaan `1.00`:

- **Exploit Code Maturity (`E`)**: `X` (`1.00`), `U` (Unproven = `0.91`), `P` (Proof-of-Concept = `0.94`), `F` (Functional = `0.97`), `H` (High = `1.00`)
- **Remediation Level (`RL`)**: `X` (`1.00`), `O` (Official Fix = `0.95`), `T` (Temporary Fix = `0.96`), `W` (Workaround = `0.97`), `U` (Unavailable = `1.00`)
- **Report Confidence (`RC`)**: `X` (`1.00`), `U` (Unknown = `0.92`), `R` (Reasonable = `0.96`), `C` (Confirmed = `1.00`)

## Metrik Environmental (11 Opsional)

- **Security Requirements (`CR, IR, AR`)**: `X` (`1.0`), `L` (Low = `0.5`), `M` (Medium = `1.0`), `H` (High = `1.5`).
- **Modified Base Metrics (`MAV, MAC, MPR, MUI, MS, MC, MI, MA`)**: Menggantikan metrik Base terkait bila diatur ke nilai selain `X` (`Not Defined`).

## Rumus Tepat (CVSS v3.1)

### Base Score

1. `ISS = 1 - ((1 - C) * (1 - I) * (1 - A))`
2. Jika `S == U`: `Impact = 6.42 * ISS`
3. Jika `S == C`: `Impact = 7.52 * (ISS - 0.029) - 3.25 * (ISS - 0.02)^15`
4. `Exploitability = 8.22 * AV * AC * PR * UI`
5. Jika `Impact <= 0`, `BaseScore = 0.0`.
6. Jika tidak:
   - Jika `S == U`: `BaseScore = Roundup(min(Impact + Exploitability, 10))`
   - Jika `S == C`: `BaseScore = Roundup(min(1.08 * (Impact + Exploitability), 10))`

### Temporal Score

`TemporalScore = Roundup(BaseScore * E * RL * RC)`

### Environmental Score (Khusus v3.1)

1. `MISS = min(1 - (1 - MC * CR) * (1 - MI * IR) * (1 - MA * AR), 0.915)`
2. Jika `MS == U`: `ModifiedImpact = 6.42 * MISS`
3. Jika `MS == C`: `ModifiedImpact = 7.52 * (MISS - 0.029) - 3.25 * (MISS * 0.9731 - 0.02)^13`
4. `ModifiedExploitability = 8.22 * MAV * MAC * MPR * MUI`
5. Jika `ModifiedImpact <= 0`, `EnvironmentalScore = 0.0`.
6. Jika tidak:
   - Jika `MS == U`: `EnvironmentalScore = Roundup(Roundup(min(ModifiedImpact + ModifiedExploitability, 10)) * E * RL * RC)`
   - Jika `MS == C`: `EnvironmentalScore = Roundup(Roundup(min(1.08 * (ModifiedImpact + ModifiedExploitability), 10)) * E * RL * RC)`
